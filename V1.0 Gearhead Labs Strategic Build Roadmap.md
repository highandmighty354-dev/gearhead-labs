# V1.0 Gearhead Labs Strategic Build Roadmap

## Mission
Build Gearhead Labs into the best automotive math, calculator, engineering-tool, and reference platform we can make. We do not stop at “works”; we keep improving usability, completeness, accuracy, responsiveness, and polish.

## Build Order

### 1. Calculator Accordion / Drop-Down Behavior
- [x] Closed sections open with one click.
- [x] Initially open sections close with one click.
- [x] Repeated clicks reliably toggle state.
- [x] Fix committed: `f3d209e`.

### 2. Complete Calculator Library Audit — NEXT
- [ ] Verify every Lab and every calculator category is represented in the navigation.
- [ ] Verify calculator counts match the actual calculators available.
- [ ] Verify all calculators are reachable from the navigation.
- [ ] Identify missing, duplicated, orphaned, or incorrectly categorized calculators.
- [ ] Restore/add anything missing before moving to later polish work.

### 3. Calculator Navigation / UX
- [ ] Make the complete library easy to browse and search.
- [ ] Ensure category expansion/collapse behavior is consistent everywhere.
- [ ] Ensure navigation links and calculator destinations are correct.
- [ ] Preserve a clear hierarchy across Labs, categories, and individual calculators.

### 4. Individual Calculator QA
- [ ] Test every calculator's inputs and calculations.
- [ ] Verify Imperial / Metric switching.
- [ ] Verify result presentation and units.
- [ ] Test edge cases and invalid inputs.
- [ ] Check formulas for technical correctness.

### 5. Homepage / Product Polish
- [ ] Refine the homepage experience around the complete calculator library.
- [ ] Ensure calls-to-action work correctly.
- [ ] Ensure the homepage accurately represents the breadth of the platform.
- [ ] Maintain the Gearhead Labs visual identity and “THE SCIENCE OF SPEED.” positioning.

### 6. Mobile / iPhone Experience
- [ ] Test the complete site on iPhone/mobile layouts.
- [ ] Fix responsive navigation and accordion behavior.
- [ ] Fix calculator layouts, controls, typography, and scrolling where needed.
- [ ] Repeat testing across desktop and mobile after major changes.

### 7. Full Production QA Pass
- [ ] Verify all links and navigation.
- [ ] Verify all calculator counts and destinations.
- [ ] Verify responsive behavior.
- [ ] Verify visual consistency.
- [ ] Verify no console/runtime errors affecting users.
- [ ] Perform a final end-to-end user test before declaring the current build production-ready.

## Operating Rule
Complete the roadmap in order unless a discovered dependency or critical defect requires temporarily changing the sequence. After each major task, verify the live site before proceeding.
